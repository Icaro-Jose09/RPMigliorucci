# GUIA DE EVOLUÇÃO DO PROJETO

## Visão inicial

A primeira versão foi pensada como uma página editorial/premium, combinando:
- fundo off-white;
- preto;
- detalhes dourados/bege;
- tipografia serifada para personalidade;
- tipografia sans-serif para leitura;
- bastante espaço em branco;
- blocos de conteúdo com aparência de portfólio profissional.

## Atenção

Os elementos "INSIRA SUA FOTO", "NOME PROFISSIONAL", e os contatos são placeholders.

Eles devem ser substituídos depois da validação da cliente.
