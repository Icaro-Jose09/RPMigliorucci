# Landing Page — Relações Públicas

Primeiro protótipo visual da Landing Page para uma profissional de Relações Públicas, Comunicação e Estratégia.

## Objetivo desta versão

Esta versão é um protótipo navegável para apresentar a direção visual e a estrutura da página antes de inserir conteúdo definitivo, fotos, identidade visual e contatos reais.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Como abrir no VS Code

1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador.

### Opção recomendada

Instale a extensão **Live Server** no VS Code.

Depois:

1. Abra `index.html`.
2. Clique com o botão direito.
3. Selecione **Open with Live Server**.

O navegador abrirá uma URL local e atualizará a página conforme você salvar alterações.

## Arquivos

- `index.html` — estrutura da página
- `css/style.css` — todo o visual
- `js/script.js` — menu mobile, animações e ano do rodapé
- `assets/images/` — local para fotos futuras
- `assets/icons/` — local para ícones futuros
